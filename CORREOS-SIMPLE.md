# ✅ Sistema de Contacto - Solución Simplificada

## 🎯 ¿Qué es FormSubmit?

**FormSubmit** es un servicio gratuito que recibe formularios HTML y envía los datos por correo automáticamente. **No requiere instalación ni configuración de servidores**.

## ✨ Ventajas

✅ **Sin instalar nada** - Solo necesitas abrir la página en tu navegador
✅ **Sin Node.js requerido**
✅ **Sin contraseñas de Gmail**
✅ **Los correos llegan automáticamente a jorbercampana@gmail.com**
✅ **Completamente gratuito**
✅ **Funciona en cualquier dispositivo**

## 🚀 Cómo usar

### Opción 1: Servidor Simple (Windows/Mac/Linux)

**Windows (PowerShell):**
```powershell
cd C:\Users\USUARIO\Desktop\trabajoIA\Diagnostico-de-fallas
python -m http.server 8000
```

**Mac/Linux (Terminal):**
```bash
cd ~/Desktop/trabajoIA/Diagnostico-de-fallas
python3 -m http.server 8000
```

Luego abre en tu navegador:
```
http://localhost:8000
```

### Opción 2: Abrir directamente

Solo abre el archivo `index.html` con tu navegador:
```
c:\Users\USUARIO\Desktop\trabajoIA\Diagnostico-de-fallas\index.html
```

**O** arrastra el archivo `index.html` a tu navegador.

## 📧 Usar el formulario

1. Haz clic en el botón **"Contactar"** en la barra superior
2. Rellena el formulario:
   - **Nombre**: Tu nombre
   - **Correo**: Tu correo de contacto
   - **Asunto**: El tema de tu consulta
   - **Mensaje**: Los detalles de tu problema
3. Haz clic en **"📧 Enviar Mensaje"**
4. ¡Listo! El correo llegará automáticamente a jorbercampana@gmail.com

## 🔄 Flujo de envío

```
Tu navegador
    ↓
  HTML Form
    ↓
FormSubmit.io (servicio gratis)
    ↓
jorbercampana@gmail.com (recibe el correo)
```

## ⚠️ Importante

El primer envío con FormSubmit requiere **confirmación por email**:

1. **Primera vez**: Recibirás un email de confirmación en tu casilla
2. Haz clic en el link de confirmación
3. **A partir de ahí**: Los correos se enviarán directamente sin confirmación

## 🎯 Resultados esperados

Después de enviar el formulario:
- ✅ Recibirás un mensaje de confirmación en pantalla
- ✅ El modal se cerrará automáticamente
- ✅ El correo llegará a jorbercampana@gmail.com
- ✅ Si hay error, verás un mensaje indicando el problema

## 💡 Si no funciona

### "El correo no llegó"
- Verifica que el correo de confirmación se haya enviado a tu casilla
- Haz clic en el link de confirmación
- Intenta enviar de nuevo

### "Error en el formulario"
- Asegúrate de completar todos los campos
- Verifica que el email esté en formato correcto (ejemplo@gmail.com)
- Intenta nuevamente

### "No me llegó la confirmación"
- Revisa carpeta de Spam/Basura
- Espera 5 minutos
- Intenta con otro correo
